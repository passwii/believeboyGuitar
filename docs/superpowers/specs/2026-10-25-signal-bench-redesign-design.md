# 站点重设计 — 方向收敛与设计契约

日期：2026-10-25
状态：方向已确认（02 为主、08 备选、浅色单世界），待写实现计划
相关预览：`public/design-previews/modern-directions/`

本文只记录设计决策，不改代码。令牌数值在 D2 定稿前均为草案。

## 1. 结论

- **主方向**：02 声波工作台（Waveform Bench）。
- **备选**：08 开放排练桌（Session Desk）——只用它的信息结构，不用它的配色。
- **世界模型**：全站一个世界，浅色为默认。删除「读值区浅色 / 工具区暗色」的双区换皮。
- **签名交互**：拍点驱动波形。节拍器与 TAB 共用同一个音频时钟。
- **退出的方向**：03 排练海报、04 指板地形、06 灯光舞台不再参与比较；05、07 只作为控件与线路的素材来源。

## 2. 为什么是 02

产品要回答的问题只有一个：**打开就能练**。所以首屏必须是「速度 / 拍号 / 开始」，而不是一段自我介绍。

02 是八个方向里唯一把技术感落在真实功能上的：

- 波形不是装饰，它就是当前 BPM 与拍点的可视化。改速度，波形密度跟着变。
- 浅色底让 TAB 数字、谱线、正文都保持可读，不需要再维护第二套暗色令牌。
- 迁移成本最低：现有冷白画布可以逐条替换，而不是把 383 行 `globals.css` 推倒重写。

08 的价值在结构而不是视觉：TAB 与节拍器并排、控制在上、结果在下。这套信息顺序直接吸收进 02，不必单独成稿。

## 3. 世界模型

**信号台。** 不是舞台，也不是笔记本。练习时面对的是仪器读数：速度、拍点、谱面位置。

- **谁用**：一个人，一把琴，桌边或床边，手机与笔记本都有。
- **光线**：室内常光。所以浅色是主场景，不是审美偏好。
- **语气**：精确、安静、有一点机械感。不用营销句，不用「解锁」「进阶」这类词。
- **记忆点**：一条会跟着拍点扫过的波形。用户离开后应该记得这个，而不是记得某个渐变色。

## 4. 设计原则（替换 DESIGN.md §2）

1. **首屏就是仪器。** 最高频的两个动作（开始节拍、看谱）必须在第一屏可达，说明文字排在后面。
2. **动效必须有信息。** 全站只保留一个持续运动：拍点驱动的波形与播放头。装饰性入场最多一次，且只用于首屏。
3. **一个世界，一套令牌。** 不再靠换皮区分「读」与「用」；区分靠版式与密度。
4. **图标是结构的一部分。** 导航、工具入口、状态都用同一套 1.5px 线宽图标，不用 emoji、不用字符代替。
5. **数字用等宽。** BPM、拍号、小节、品位一律 `tabular-nums`，避免读数跳动。
6. **删优先于加。** 新令牌、新字号档位、新曲线都要能说出它替代了谁。

## 5. 令牌草案

数值取 02 预览稿，D2 需要用现有对比度测试逐条验过再定稿。

### 色彩

| 令牌 | 草案值 | 用途 |
| --- | --- | --- |
| `--color-canvas` | `#F1F2EC` | 页面底色，也是 PWA theme/background |
| `--color-surface` | `#FBFCF8` | 抬升一层：仪器面板、谱面 |
| `--color-surface-muted` | `#E4E9E1` | 次级底：搜索、未选中分段 |
| `--color-ink-950` | `#1D2520` | 标题、读数 |
| `--color-ink-700` | `#49534C` | 正文、次级说明 |
| `--color-ink-500` | `#5C6A61` | 元信息 |
| `--color-accent-700` | `#267B55` | 主操作、选中、链接、波形 |
| `--color-accent-600` | `#2E8C62` | 画布上的填充 |
| `--color-on-accent` | `#FFFFFF` | 强调底上的文字 |
| `--color-rule` | `#C9D1C8` | 发丝线 |
| `--color-control-edge` | `#6B766E` | 控件边界 |
| `--color-board-800/900` | 保留暖木色 | 指板仍是实物，不为统一而改灰 |

墨色三级需在 canvas / surface / surface-muted 上均 ≥ 4.5:1。

### 字体

- **UI / 正文**：系统无衬线栈（PingFang SC 等），数值 `tabular-nums`。
- **展示字**：这是 D2 唯一待拍板的资产问题。
  - 方案 A：继续系统栈，靠字重与字号拉开层级，零外部请求。
  - 方案 B：自托管一个可变字面（仅拉丁，中文回退系统），首屏加载约 30–60KB。
  - 倾向 B，但必须先确认离线与 PWA 预缓存预算。
- **等宽**：仅用于数据与谱面刻度，不用于「技术感」装点。

### 字号、间距、圆角

- 保留六档：`display / title / body / label / meta / micro`。新增档位必须先替换一档，不能加第七档。
- 圆角三档不变：`control 10px / card 14px / pill`。
- 页面宽 1120px、阅读列 40em 不变。
- 阅读区外的间距改用 4px 基准的 8 档节奏，避免现在的「到处 1.25rem」。

### 动效

- `--ease-standard: cubic-bezier(.32,.72,0,1)` 保留，用于状态过渡。
- 新增 `--ease-scan: linear`，只给波形扫描与播放头，因为节拍必须是匀速的。
- 时长两档：150ms 状态、240ms 面板展开。
- `prefers-reduced-motion` 下波形静止、播放头改为跳格。

### 图标

- 内联 SVG，24px 网格，1.5px 线宽，圆头。
- 首批需要：首页、资料、工具、节拍器、播放、暂停、加减、搜索、筛选、返回、外部链接、安装。
- 不引入图标库依赖。

## 6. 页面职责

| 页面 | 首屏必须给出 | 说明 |
| --- | --- | --- |
| 首页 | 开始节拍 + 当前练习 + 最近资料 | 从「学习目标列表」改为「练习台」 |
| 资料库 | 搜索、结果、筛选 | 结构保留，视觉重做 |
| 正文 | 标题、目录、正文 | 阅读列不变，去掉旧的大标题块 |
| 工具间 | 五个工具的入口 | 从编号列表改为图标网格，但不用卡片墙 |
| 节拍器 | 拍号、速度、开始 | 波形成为主视觉，控件在拇指区 |
| TAB 组件 | 谱面、当前音符 | 与节拍器共用时钟，播放时高亮 |

首页从「书桌」改成「今天练什么」：节拍器快捷开始、继续上次的谱、最近整理的资料。原 `home.goals` 是否保留，D3 定。

## 7. 签名交互

一个时钟，三处反馈：

1. 节拍器的波形按 BPM 脉动，拍点处出现一次亮峰。
2. 播放头按小节推进，回卷时不跳变。
3. 若页面同时有 TAB，当前拍对应的音符高亮；改速度时三处同步，不各走各的。

实现上仍用现有 lookahead 调度器（`lib/metronome-audio.ts`），只增加一个「当前拍」订阅，不给 React 增加每帧渲染。

## 8. 与现有系统的冲突

这些必须同批处理，否则测试会挡：

- **`DESIGN.md` 重写**：§1 定位、§2 原则、§3 令牌、§4 平台层都要改；不能只改令牌表。
- **`tests/design-system.test.ts`**：删除 `.zone-tools` 那条用例，新增波形/播放头的减弱动效断言；字号阶梯与死令牌两条保留。
- **`app/tools/layout.tsx` 与 `.zone-tools`**：整套删除，同时删掉 `SiteNav` 的换皮分支。
- **`SiteNav` 图标化**：文字导航改图标 + 文字，dock 同步；命中区仍 ≥ 44pt。
- **PWA `themeColor` 与 `app/manifest.ts`**：改为新 canvas 色，并跑一次离线回归。
- **`content/content.css`**：正文排版跟着改字号与间距，但不得引入正文内联样式。

## 9. 不做

- 不做暗色模式切换（新世界本身就是浅色，不提供第二套）。
- 不做卡片墙、不做营销式 Hero、不做滚动视差。
- 不引入动画库或图标库。
- 不改 `content/manifest.ts` 的数据结构，除非 D3 明确需要。
- 不重做五个工具的业务逻辑，只换外壳。
