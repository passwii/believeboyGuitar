# 练习节拍器统一控制设计

## 目标

统一工具页、资料库指板练习与周练谱例中的节拍器操作：练习加减按钮每次调整 5 BPM；桌面宽屏的周练谱例提供固定在视口右侧中部的迷你控制；空格键在所有有节拍器的页面执行当前播放器的开始/暂停操作。周练暂停后保留谱面位置，恢复时从当前位置继续。

## 页面与状态

- `/metronome` 保留现有节拍器和 Escape 停止操作，空格键改用共享的按键过滤规则。
- `/library/fretboard-scale` 保留现有 Space 与 Enter 作用；Space 由共享规则绑定到指板页的练习节拍器。
- `/practice/week-*` 的 `TabDrill` 使用共享 Space 规则。空格键和页面按钮调用同一个切换函数。
- `TabDrill` 的暂停保存已完成的节拍进度及谱面高亮；继续时从下一个节拍接上。播放速度调整为 5 BPM 步进。
- 当前暂停的 beat offset 以节拍数保存，恢复后按当前 BPM 继续。谱面高亮按同一音频时钟计算，拍号循环和音频调度保持同步。

## 桌面悬浮控制

- 仅在宽屏周练详情页显示，右侧固定、垂直居中，并在页面布局中预留侧栏空间。
- 紧凑状态持续显示当前 BPM、运行状态和开始/暂停按钮；展开后显示 ±5 BPM 按钮。
- 初始保持紧凑。用户手动展开后继续保持展开，直到手动收起；滚动不改变展开状态。
- 手机与窄桌面继续使用谱例标题区域的行内控件。桌面宽屏隐藏重复的行内控件。
- 悬浮控件直接读取并修改 `TabDrill` 的现有状态，不创建额外音频实例或时钟。

## 空格键规则

- 共享按键处理器用于 `/metronome`、指板练习与周练谱例，按下空格时调用当前播放器的 toggle。
- 忽略默认已处理、长按重复、输入法组合和带修饰键的事件。
- 焦点位于原生交互控件、可编辑区域或自定义 slider 时不接管空格；指板的 `role="group"` 仍可用空格控制节拍器。
- 只有实际执行节拍器快捷键时阻止页面滚动。
- 桌面开始/暂停按钮标注 `aria-keyshortcuts="Space"`，练习页提供可见提示。

## 不在本次范围

- 跨设备同步 BPM 或播放状态。
- 给节拍器增加新的拍号、音色或独立播放器。
- 改变工具页现有 Escape 行为。
