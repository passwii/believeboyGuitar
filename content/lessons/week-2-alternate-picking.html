练习说明

练法

重点是右手：下拨、上拨、空拨都保持方向交替。每天先弹「每日必弹」。

⊓ / ∨ 是下拨 / 上拨；括号是空拨，手继续走但不碰弦。

每日必弹

3 弦空弦：四分 → 八分 → 三连音 → 十六分。保持 ♩=120。

  • 四分：全下拨。
  • 八分：下上，第一音下拨。
  • 三连音：下上下｜上下上。
  • 十六分：严格下上，手臂不加速。

要点

  1. 周一：C 和弦分解，♩=120。5→1→5 弦；方向跨弦连续。
  2. 周二：D 和弦三连音，♩=90。D → Dadd9 → D → Dsus4 → D；1 弦 3 品用小指。
  3. 周三：A / D 和弦音，♩=110。前半八分，后半三连音；只交替，不经济拨。
  4. 周四：空拨，♩=120。Em → G、A → G；括号动作照样按十六分走。
  5. 周五：切分音，♩=100。Gm；延音时右手不停。
  6. 周六：击弦与 Q.C.，♩=100。G Riff；3.5 品是轻推弦，不是新品位。

速度

♩=90 周二；♩=110 周三； ♩=120 每日必弹、周一、周四；♩=100 周五、周六。 方向错了就退慢。

易错

  • 换弦重新起拨。方向跨弦继续。
  • 空拨手停住。没声音也要挥。
  • 延音重新响。让前音继续。
  • 击弦 / Q.C. 当新品。击弦靠左手；Q.C. 是推弦。

核对

拨片与延音有整理推测。练前请对照原书核对，尤其周六。
