1. 一句话认识这台机器

Pocket AMP 是一台桌面式（非踩钉）综合效果器，把「6 个效果模块 + 箱头模拟 + IR 箱体模拟 + 声卡 + 蓝牙伴奏 + OTG 内录」塞进一个巴掌大的盒子里。

核心数字：

  • 6 个效果模块：FX → AMP → MOD → DLY → REV → CAB（顺序可自定义）
  • 6+1 效果：FX 槽可同时装 2 个前级类效果（降噪 + Boost / 降噪 + 压缩）
  • 80 个预设位：P01–P40 出厂预设，P41–P80 用户自定义
  • 其中 P36–P40 为贝斯预设
  • 20 个箱头模拟：1–15 吉他，16–20 贝斯
  • 20 个 IR 箱体模拟：1–15 吉他，16–20 贝斯
  • 7 种调制 / 5 种延时 / 6 种混响
  • 60+ 个效果
  • 44.1kHz / 24bit，动态范围 105dB
  • 内置电池 1450mAh，续航约 7 小时，充电约 5 小时
  • 没有踩钉，但有 BANK 模式（4 预设一组，用面板按键模拟踩钉）
  • 支持外接 MIDI 踏板（如 Chocolate Plus）来扩展出真正的踩钉

2. 一分钟上手

2.1 最快出声路径

  1. 吉他 → 后置面板 ⑤ IN（1/4" MONO）
  2. 耳机 → 后置面板 ④ 耳机输出；或 音箱/调音台 → ⑥ OUT（1/4" MONO）
  3. 拨后置面板 ① 电源开关（长按/拨动，按实物）
  4. 屏幕上出现「主界面」，显示 P08、100、六个模块图标
  5. 旋转 PARA 旋钮把光标选到预设编号，继续旋转即可快速换预设
  6. 转动 Master 旋钮控制总音量

⚠️ BT 音量 和 USB 输入音量 不受 Master 旋钮控制，需要在手机/电脑侧调。

2.2 主界面看什么

主界面（开机默认页）显示：

位置 内容
中间大号 当前预设编号（如 P08）
其下数字 当前预设音量（如 100）
六个图标 FX / AMP / MOD / DLY / REV / CAB 的顺序 + 开关状态（亮=启用，灭=关闭）
状态区 电池图标、BT 图标

六个图标全灭 = 整机 Bypass（直通）。

2.3 模块操作界面

在主界面再单击一次 HOME，进入「模块操作界面」，可以看到当前预设用的具体效果：

8 号键是双功能键：既是 HOME，也是 BT 开关（长按切换）。

3.2 后置面板

编号 接口 说明
① 电源开关 开/关机
② USB 接口（Type-C） 充电 / 电脑声卡 / 电脑数据交换 / OTG 内录 / 支持 MIDI 踏板

3.3 USB 口的四种用途

  1. 充电：给内置电池充电
  2. 电脑声卡：Pocket AMP 作为电脑音频接口
  3. 数据交换：用 M-EFCS 电脑软件编辑音色、导入/导出、恢复出厂、固件升级
  4. OTG 内录：用「另购的 OTG 转换器 + 原厂 USB 线」连接手机，进入任意视频/音频录制 APP 直接实时录制

4. 预设系统（80 个音色位）

4.1 预设分布

范围 内容
P01–P35 出厂预设（吉他）
P36–P40 出厂预设（贝斯）
P41–P80 用户自定义
  • 出厂预设可以编辑并覆盖保存，也可以在此基础上改。
  • 恢复出厂设置时，可以只恢复前 40 个，也可以一次恢复全部 80 个。

4.2 切换预设

  1. 用 PARA 旋钮把光标选到「预设编号」
  2. 旋转 PARA → 快速浏览/切换预设
  3. 也可以用 <** / **> 按键逐个切换

4.3 Save to（保存到）

长按 PARA 1 秒 → 出现 Save to 界面。

  • 用于把当前调好的音色保存到指定预设编号。
  • 在此界面单击 HOME 可退出，回到主界面。

4.4 Swap to（交换）

长按 PARA 2 秒 → 出现 Swap to 界面。

  • 用于交换两个预设的位置（把 A 换到 B，B 换到 A）。
  • 同样是单击 HOME 退出。

「保存」和「交换」的区别很重要：

  • 想覆盖某个位置 → 用 Save to
  • 想调换顺序 / 整理音色库 → 用 Swap to

4.5 BANK 模式（没有踩钉的替代方案）

进入方式（两种等价）：

  • 同时按 <** 和 **>
  • 同时按 VOL- 和 VOL+

规则：

  • 4 个预设为一组（Bank）
  • 组内按键映射固定为：
按键 组内位置
VOL- 第 1 个预设
VOL+ 第 2 个预设
< 第 3 个预设
> 第 4 个预设

切组：

  • VOL- + VOL+ 同时按 = BANK-（上一组）
  • < + > 同时按 = BANK+（下一组）

退出： 按 HOME。

BANK 模式下的屏幕行为：

  • 下方 4 个预设编号区域，当前所在的会亮黄灯
  • 切换 Bank 时，上方预设编号不变，下方 4 个号码闪烁
  • 按下 VOL-/VOL+/</> 其中一个 → 音色跳到该按键对应的音色，对应区域亮黄灯，上方编号同步更新

读法示例：

  • 下方第 1 个编号区亮黄灯 → 当前在 01
  • 按 VOL+ → 下方第 2 个区亮黄灯 → 当前在 02

这套映射本质上是把「4 个面板按键」当作「4 个踩钉」用，方便现场按顺序走歌。

5. 调音器（Tuner）

进入： 同时按 VOL- 和 VOL+ 退出： 单击 VOL- 或 VOL+ 任意一个

界面有两个可选项：

项目 含义 范围
Refer to A 音参考频率 430 – 450 Hz
Volume Bypass 状态下的输入音量 —

界面还有一个 IN 输入孔信号实时展示条，用来判断信号强度。

〔建议〕调音时先把 Volume（Bypass 输入音量）调到能稳定驱动显示条的位置；参考频率按你的演奏场景选（乐队统一 440Hz，部分老唱片/管乐场景会用到 442Hz）。

6. 六大效果模块详解

6.0 总览

FX → AMP → MOD → DLY → REV → CAB

（顺序可自定义）

模块 数量 内容
FX 3 种搭配 Noise Gate / NG+Boost / NG+Compress，外加 AI Gate MS
AMP 20 1–15 吉他箱头前级；16–20 贝斯箱头前级
MOD 7 Chorus / Phaser / Tremolo / Flanger / Vibrato / Univibe / Autofilter
DLY 5 Analog / Ducking / dTape / Dual / Lofi
REV 6 Room / Hall / Swell / Spring / Shimmer / Cloud
CAB 20 1–15 吉他 IR 箱体；16–20 贝斯 IR 箱体

6.1 Ⅰ · FX 多功能模块

FX 模块有三种搭配方式，可实现「6+1 个效果同时使用」：

  • 方式 A：Noise Gate
  • 方式 B：Noise Gate + Boost
  • 方式 C：Noise Gate + Compress

1) Noise Gate++（降噪）

参数 说明
Gate 调节 AI 降噪的力度。调到 0 = 关闭降噪

〔建议〕把 Gate 当作「门槛」来用：清音/单线圈拾音底噪大的时候往上推，直到抬手不弹时噪声收干净，但不要推到音符尾音被切断。高增益音色可以推高一些。

2) Boost（激励，可叠加降噪）

参数 说明
Gate AI 降噪力度，0 = 关闭降噪
Gain 激励效果的增益度

〔建议〕Boost 放在 AMP 之前，用来「推箱头」：Gain 小一点（10–25）推清音到轻破，Gain 大一点（35–60）推高增益做紧致主音。

3) Compress（压缩，可叠加降噪）

参数 说明
Gate AI 降噪力度，0 = 关闭降噪
Sustain 综合了阈值 + 压缩比等参数，数值越大压缩越明显
Attack 信号超过阈值后压缩器的启动时间。越大 = 启动越慢 = 音头更突出；越小 = 启动越快
Level 该模块的最终输出音量

〔建议〕

  • 想做「清音更整齐」：Sustain 中等，Attack 偏快（小值），Level 补回音量
  • 想做「Funk 打击感」：Attack 偏慢（大值），保留音头
  • 想做「无限延音」：Sustain 大，Level 适当提

4) AI Gate MS（智能降噪）

基于统计偏差跟进模型的智能算法。

参数 说明
Gate 打开 Gate 的阈值。持续监测输入信号电平：阈值越高，开门越苛刻（只有更强的信号能通过）；阈值越低，越多信号能通过
Bias 偏置提前量。让 AI 降噪模型提前「准备」应对即将出现的噪声/信号变化。能提前预测噪声变化趋势并调整偏置时，模型就能更准确地在噪声出现时抑制它，减少干扰，提高降噪的及时性和准确性

〔建议〕AI Gate MS 适合「有持续底噪、又有细腻动态」的场景（比如高增益 + 长音）。先设 Gate 找到「安静时的边界」，再用 Bias 微调「噪声刚要出现时的手感」——Bias 给得太大会把弱奏的音头也一起吃掉。

说明：Gate 与 Bias 是两个不同维度的控制。Gate 决定「多大声才放行」，Bias 决定「提前多少开始动手」。

6.2 Ⅱ · AMP 箱头前级模拟模块

编号 1–15 = 电吉他音箱模拟；16–20 = 贝斯音箱模拟。

五个参数：

参数 说明
Gain 前级增益 / 失真度
Level 该模块输出音量
Bass 低频
Mid 中频
Treble 高频

即：三段 EQ 就在 AMP 模块里（Bass / Mid / Treble）。

〔建议〕

  • Gain 与 Level 配合：提高 Gain 会同时提高响度和压缩感，用 Level 把整体电平拉回来，才能公平对比音色。
  • 三段 EQ 调法：想「更亮更靠前」→ Treble ↑ 一点，Mid ↓ 一点；想「更厚更暖」→ Bass ↑，Treble ↓；想「切进混音」→ 适当提 Mid。
  • 高增益时把 Bass 先降 1–2 格再加 Gain，能避免低频糊成一团。
  • 贝斯预设（P36–P40）请选 16–20 号箱头，否则音色会非常薄/怪。

❓待确认：1–15 与 16–20 的具体箱头型号名。说明书的模块界面示例里出现过 9PvEV5150（疑似 EVH 5150 类）这样的命名，但完整名单未在说明书列出，需在 M-EFCS 软件或实机里逐一读取后补全。

6.3 Ⅲ · MOD 调制模块（7 种）

1) Chorus（合唱）

参数 说明
Speed 效果速度
Depth 效果深度
Mix 干声 / 湿声比例

〔建议〕清音加宽：Speed 慢、Depth 中、Mix 30–40%。做「80 年代大合唱」：Speed 中、Depth 大、Mix 50%。

2) Phaser（相移）

参数 说明
Speed 效果速度
ParamA MidCut（中频削减），数值越大中频削减越多。这个参数主要为失真音色设计
ParamB Resonance（共振强度）
Feedback 湿声反馈量

〔建议〕ParamA 是给失真音色的「雕刻刀」：失真音色用相移容易糊中频，用 MidCut 挖开中频再叠相移，扫频感更清楚。

3) Tremolo（颤音）

用低频振荡器控制信号电平。

参数 说明
Speed 效果速度
Depth 效果深度
Level 该模块的最终输出音量

4) Flanger（弗朗格）

原理与合唱类似，但用更短的延时时间并增加再生（反馈），产生夸张的上下扫频。

参数 说明
Speed 效果速度
Depth 效果深度
Feedback 湿声里扫频效果的反馈量
Mix 干声 / 湿声比例

5) Vibrato（震音）

调制输入信号的音高，效果类似声乐家的颤音。

与 Chorus / Flanger 相反：没有干信号与音高调制信号混合。

参数 说明
Speed 效果速度
Depth 效果深度

〔建议〕Vibrato 是「全湿」型效果，用少量 Depth 做微妙摇曳，Depth 大就会变成明显的「走音感」，慎用于和弦。

6) Univibe（多谐振荡器）

独特音色，是合唱 + 相移的结合。

参数 说明
Speed 效果速度
Depth 效果深度
Mix 干声 / 湿声比例

7) Autofilter（自动滤波器）

通过设定频率让滤波器有规律地工作，吉他和贝斯都能用。

参数 说明
Speed 效果速度
Min 扫频的最低频率。数值开大后，湿声的中低频更突出
Max 扫频的最高频率。数值开大后，湿声的中高频更突出
Mix 干声 / 湿声比例
Feedback 反馈量

〔建议〕Funk / 贝斯 slap 用 Autofilter 做「哇音感」。Min 与 Max 拉开的区间决定扫频幅度，Feedback 决定扫过的「锐度」。

6.4 Ⅳ · DLY 延时模块（5 种）

通用说明：Time 在说明书里写作「延时效果时间速度参数」，并给了 BPM 区间（数值越大间隔越短，因为是 BPM 语义）。Analog / Ducking / dTape / Lofi 为 600–60 bpm，Dual 为 1200–120 bpm。

1) Analog（模拟延时）

模拟电子管信号的延迟效果，音色复古、温暖。

参数 说明
Time 延时时间速度参数，600–60 bpm
Feedback 延迟的反馈次数
Mix 干湿比
Phaser 在 Delay 湿声里增加相移效果，调节相移使用量
Pitch 给湿声加一点失谐，是轻微移调的声音，复古迷人

2) Ducking Delay（闪避延迟）

在处理延时湿音时，在湿音发声的前段加入降噪，抑制湿音前段，形成「前面闪避」、声音慢慢增大的听感。

通过非常轻微的闪避，延迟的动态更多是「感觉到」而不是「听到」。

参数 说明
Time 600–60 bpm
Feedback 反馈次数
Mix 干湿比
Unpack 调大后，可解除湿声后段音量的突然上升感，让延时动态更平缓
Speed 在湿声里增加合唱效果的速度
Depth 合唱的深度

〔建议〕Ducking 是「弹的时候不吵、不弹的时候自己浮出来」的延时，非常适合主音+伴奏都用一个预设的场合。

3) dTape（磁带延时）

复刻磁带机特有的延时风格，既有专业磁带机的温暖丝滑，也能模拟磁带褶皱、偏差等真实状况。

参数 说明
Time 600–60 bpm
Feedback 反馈次数
Mix 干湿比
Grit 承担 TAPE BIAS 的角色：调整磁带机偏差，从「欠偏磁」到「过偏磁」，听起来像湿声过载。用于调整湿声的动态范围与余量(headroom)
Speed 承担 TAPE CRINKLE 的角色：调整磁带不规则的程度，包括摩擦、折痕、拼接和污染物。最小值 = 清新干净的新磁带；最大值 = 被折腾腐蚀多年的磁带
Depth 控制机械相关的带速波动量，会产生自然的磁带式调制（有点像合唱）。最小 = 状态极好、保养到位的磁带机；最大 = 需要送修的磁带机；中间值 = 自然的磁带味

4) Dual Delay（双延迟）

两个独立的延时回音，第一个回音与第二个回音的时差能做出很有趣的延迟节奏效果。

参数 说明
Time 1200–120 bpm（比其他延时范围更宽/更快）
Feedback 反馈次数
Mix 干湿比
Time-Mode 调节两个回音之间的时差。最小值 ≈ 没有时差；数值越大时差越大
Speed 湿声里增加的合唱速度
Depth 合唱深度

〔建议〕Time-Mode 是 Dual 的灵魂：想要「乒乓/对拍」感就把它拉大，想要「叠加加厚」就留在小值。

5) Lofi Delay（低保真延时）

特殊、复古、带有破坏性的延时，湿声里体现滤波器、黑胶唱片、噪音低保真等多种感觉。

参数 说明
Time 600–60 bpm
Feedback 反馈次数
Mix 干湿比
Grit 调大后听起来像湿声过载
Speed 湿声里增加的合唱速度
Depth 合唱深度

6.5 Ⅴ · REV 混响模块（6 种）

1) Room（房间混响）

模拟结构简单的小房间：许多反射被房间中的软材料吸收，声音被墙壁反射。

参数 说明

LPass 低通，仅作用于湿音
Depth 让湿声产生音调的小幅度周期性升降，得到复古迷人的背景声

2) Hall（大厅混响）

宽阔、轻微散射的感觉，模拟宏大环境声音。

参数 说明
Decay —
Mix —
HPass —

3) Swell（膨胀混响）

在干信号之后逐渐带入混响，两个信号间自然衔接，获得轻微上升效果与演变氛围感——就像有个控制混响湿音的音量踏板。

参数 说明

注：说明书正文用的参数名是 RiseTime，在 Mix 说明里简写成 RiseT，是同一个参数。

4) Spring（弹簧混响）

常见混响类型：信号送入弹簧槽，拾音器捕捉弹簧的共振声。特点是来自弹簧的独特颤抖感。

〔建议〕Spring 想要「冲浪吉他」味：Combs 大一点、Decay 中等、HPass 提起来避免浑浊。

5) Shimmer（微光混响）

湿声里存在音高偏移的声音。调 Pitch 可以得到不和谐音程（营造恐怖背景声，很有创造性的用法），也可以得到和谐音程（「自带美颜」的声音，像天堂般在开阔土地上从微光到灿烂）。

6) Cloud（云混响）

华丽的大型环境混响，「声音像是从云层卷积而来」——只弹一个音符，湿声里就有非常多的声音从各处传来，听起来非常宽广。

参数 说明
Decay —

HPass —
LPass —
Diffusion 扩散度，调节环境维度感。参数增大时，早期反射的湿音被软化，听起来更平滑，模糊了延迟和混响之间的界限

6.6 Ⅵ · IR CAB 箱体模块

编号 1–15 = 电吉他箱体模拟；16–20 = 电贝斯箱体模拟。

参数 说明
Level 箱体输出音量
Low cut 低切频点，可选 20 – 300 Hz。选 300Hz 表示 300Hz 以下低频全部被抑制
High cut 高切频点，可选 18000 – 5000 Hz。选 5kHz 表示 5000Hz 以上高频全部被抑制

〔建议〕

  • Low cut：录音/乐队合奏时切到 80–120Hz 让低频给贝斯和底鼓让位；独奏练习保留低一些更饱满。
  • High cut：高增益音色切到 6.5k–8kHz 能去掉「沙沙的毛刺」；清音可以留到 10k 以上保持空气感。
  • CAB 的 Low/High cut 是最后一道「音色成型」，比 EQ 更有效——先在这两个切除点做减法，再回头动 AMP 的三段 EQ。

❓待确认：1–15 与 16–20 的具体箱体型号名（说明书未列出完整名单）。模块界面示例里出现过 8Dizzlv30（疑似 Diezel 类）的命名风格，需在 M-EFCS 里逐一读取补全。

6.7 效果链顺序调整

6 个模块的顺序可以自定义。

  • 在「模块操作界面」里可以调节 6 个模块的连接顺序。
  • 默认顺序：FX → AMP → MOD → DLY → REV → CAB
  • 模块的开关状态就是主界面上那 6 个图标；全灭即整机 Bypass。

〔建议〕顺序改变的听感差异：

  • MOD 放 DLY 前 vs 后：放前面（默认）是「调制被延时重复」，放后面是「被延时的信号再被调制」，后者更迷幻。
  • REV 放 CAB 前 vs 后：混响在箱体前 = 混响被箱体染色（更真实）；混响在箱体后 = 混响更「Hi-Fi」更独立（默认）。
  • FX 一定要在最前（降噪/压缩/Boost 属于前级类，放后面逻辑会错）。

7.4 Loopback（声卡回环）功能

常见声卡功能，可在软件里开/关，出厂默认开启。

状态 录音结果
开 电脑/手机里的音乐声会与乐器声同时录进同一轨道（混合录制，包含 USB 和 BT 的音乐声）
关 用 Pocket AMP 做声卡录音时，只录到 IN 接口的乐器声，便于电脑录音时乐器分轨录音

〔建议〕做翻弹/伴奏视频 → 开 Loopback（一次录好）；做正经分轨制作 → 关 Loopback。
